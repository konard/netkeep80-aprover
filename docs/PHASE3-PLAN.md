## Архитектурные решения Фазы 3

### Структура парсеров трёх нотаций

```
┌─────────────────────────────────────────────────────┐
│  Файловый ввод                                      │
│  • .mtl (формальная нотация)                        │
│  • .astr (строковые ачисла)                         │
│  • .anum (четверичные ачисла)                       │
└───────────────┬─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────────────────┐
│  Маршрутизатор по расширению файла                  │
│  • .mtl  → formalParser                             │
│  • .astr → stringAnumParser → formalParser          │
│  • .anum → quatParser → stringAnumParser → formal   │
└───────────────┬─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────────────────┐
│  Единый AST (формальная нотация)                    │
│  → Нормализация                                     │
│  → Верификация                                      │
└─────────────────────────────────────────────────────┘
```

### Новые модули

```
src/core/
├── lexer.ts          # (существует) Лексер формальной нотации
├── parser.ts         # (существует) Парсер формальной нотации
├── fileIO.ts         # (реализован) Файловые операции
├── stringAnum.ts     # (реализован) Парсер строковых ачисел
└── quatAnum.ts       # (реализован) Парсер четверичной нотации
```

### Реализованные функции fileIO.ts

- `readFileContent(file)` — чтение содержимого файла
- `isSupportedFile(filename)` — проверка поддерживаемого расширения
- `getFileExtension(filename)` — получение расширения файла
- `getFilePreview(content)` — получение превью для списка недавних
- `getRecentFiles()` / `addRecentFile()` / `removeRecentFile()` — история файлов
- `saveAutosave()` / `loadAutosave()` — автосохранение
- `formatResultsForExport(results, options)` — форматирование результатов
- `downloadFile(content, filename)` — скачивание файла
- `openFileDialog(accept)` — диалог выбора файла

### Реализованные функции stringAnum.ts

- `parseStringAnumLine(line)` — парсинг одной строки в AST цепочку
- `parseStringAnum(content, options)` — парсинг .astr файла в File AST
- `parseStringAnumExpr(content)` — парсинг строки как одного выражения
- `toStringAnum(node)` — обратная конвертация AST в строку
- `isStringAnumExpr(node)` — проверка, является ли AST строковым ачислом
- `stringAnumToFormal(str)` — конвертация строки в формальную нотацию
- `stringAnumFileToMtl(content)` — конвертация .astr файла в .mtl
- `visualizeConversion(str)` — визуализация шагов преобразования
- `getStringAnumStats(str)` — статистика строкового ачисла

### Реализованные функции quatAnum.ts

- `isValidAbit(char)` — проверка валидности абита
- `validateQuatAnum(content)` — валидация контента (символы + скобки)
- `cleanQuatAnum(content)` — очистка от пробелов и комментариев
- `parseAbitToAST(abit)` — парсинг абита в AST (Male/Female/Link)
- `quatAnumToFormal(content)` — конвертация в формальную нотацию
- `quatAnumToStringAnum(content)` — конвертация в строковое ачисло
- `parseQuatAnumLine(line)` — парсинг одной строки
- `parseQuatAnum(content, options)` — парсинг .anum файла в File AST
- `parseQuatAnumExpr(content)` — парсинг как одного выражения
- `toQuatAnum(node)` — обратная конвертация AST в строку абитов
- `isQuatAnumExpr(node)` — проверка, является ли AST четверичным ачислом
- `quatAnumFileToMtl(content)` — конвертация .anum файла в .mtl
- `visualizeQuatConversion(content)` — визуализация шагов преобразования
- `getQuatAnumStats(content)` — статистика (счётчики абитов, глубина, баланс)
- `isQuatAnumContent(content)` — проверка, может ли контент быть .anum файлом
