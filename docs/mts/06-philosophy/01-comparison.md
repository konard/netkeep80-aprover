# Сравнение с другими основаниями математики

> **Статус:** Шаблон для будущего контента
> **Источник:** `12-comparison-foundations.md`
> **Этап:** 5.7

## Краткое описание

Сравнительный анализ МТС с ZFC, теорией типов и теорией категорий.

## Основания для сравнения

| Система | Базовые объекты | Онтология |
|---------|-----------------|-----------|
| ZFC | Множества | Дуалистическая (элемент ∈ множество) |
| Теория типов | Термы и типы | Дуалистическая (терм : тип) |
| Теория категорий | Объекты и морфизмы | Дуалистическая (морфизм между объектами) |
| **МТС** | Связи | Монистическая (всё есть связь) |

## Планируемое содержание

1. Сравнение с ZFC
2. Сравнение с теорией типов
3. Сравнение с теорией категорий
4. Онтологическая замкнутость МТС
