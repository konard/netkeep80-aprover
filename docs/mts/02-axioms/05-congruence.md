# А2: Аксиома конгруэнции

> **Статус:** Завершён
> **Источник:** `13-axiom-system.md`
> **Этап:** 5.3

## Формула

```
{(a = c), (b = d)} -> ((a -> b) = (c -> d))
```

## Содержательно-онтологическое определение

Тождественность сохраняется под всеми конструкторами. Если компоненты связей тождественны, то тождественны и сами связи.

> Структурная прозрачность: форма связи полностью определяется формами её компонентов.

## Полная формулировка

### Прямое и обратное направления

```
// Для -> (прямое)
{(a = c), (b = d)} -> ((a -> b) = (c -> d))

// Для -> (обратное, декомпозиция)
((a -> b) = (c -> d)) -> {(a = c), (b = d)}

// Для ♂ (прямое)
(a = b) -> (♂a = ♂b)

// Для ♂ (обратное)
(♂a = ♂b) -> (a = b)

// Для ♀ (прямое)
(a = b) -> (a♀ = b♀)

// Для ♀ (обратное)
(a♀ = b♀) -> (a = b)

// Для ! (прямое)
(a = b) -> (!a = !b)

// Для ! (обратное)
(!a = !b) -> (a = b)
```

## Остенсивное определение

```
{a = c, b = d}
    ↓
(a -> b) = (c -> d)
```

Если начала равны и концы равны, то связи равны.

## Структурные свойства

| Свойство | Формула | Описание |
|----------|---------|----------|
| Конгруэнция `->` | `{a = c, b = d} -> ((a -> b) = (c -> d))` | Тождество компонентов влечёт тождество связей |
| Конгруэнция `♂` | `(a = b) -> (♂a = ♂b)` | Тождество под самозамыканием начала |
| Конгруэнция `♀` | `(a = b) -> (a♀ = b♀)` | Тождество под самозамыканием конца |
| Конгруэнция `!` | `(a = b) -> (!a = !b)` | Тождество под инверсией |
| Инъективность | Обратные направления выше | Тождество связей влечёт тождество компонентов |

## Запреты

| Запрет | Причина |
|--------|---------|
| Внешние критерии тождественности | Только структура определяет тождество |
| Тождество связей при различии компонентов | Нарушает структурную прозрачность |

## Следствия

1. **Структурная прозрачность** — форма связи полностью определяется компонентами
2. **Корректность подстановки** — тождественные выражения можно заменять в любом контексте
3. **Декомпозиция** — из тождества связей следует тождество их частей

## Примеры применения

### Пример 1: Конгруэнция по `->`

```
// Если доказано:
{♂∞ = ♂∞, ∞♀ = ∞♀}

// То следует:
(♂∞ -> ∞♀) = (♂∞ -> ∞♀)
```

### Пример 2: Декомпозиция

```
// Если доказано:
(a -> b) = (c -> d)

// То следует:
{a = c, b = d}
```

### Пример 3: Конгруэнция по `♂`

```
// Если доказано:
∞ = (∞ -> ∞)

// То следует:
♂∞ = ♂(∞ -> ∞)
```

## Философское значение

> Конгруэнция утверждает: в МТС нет скрытых свойств.

Все связи однозначно определяются своей формой. Это обеспечивает:
- **Онтологическую прозрачность** — нет "невидимых" различий
- **Корректность вычислений** — подстановки всегда корректны
- **Обратимость** — из равенства связей можно извлечь равенство компонентов
