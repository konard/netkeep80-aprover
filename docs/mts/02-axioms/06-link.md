# А3: Аксиома связи

> **Статус:** Завершён
> **Источник:** `13-axiom-system.md`
> **Этап:** 5.3

## Формула

```
be : (b -> e)
```

## Содержательно-онтологическое определение

Связь определяется направленным отношением между **началом** `b` и **концом** `e`. Конструктор `->` создаёт новую связь из двух существующих, сохраняя их структурную целостность.

> В МТС **всё есть связь**. Оператор `->` — фундаментальный способ конструирования новых связей.

## Остенсивное определение

```
b -> e
 ↓
 b
  \
   \
    e
```

Графическая форма стрелки `->` остенсивно отражает направленность от начала к концу.

## Структурные свойства

| Свойство | Описание |
|----------|----------|
| Бинарность | `->` — бинарный оператор |
| Левоассоциативность | `abc ≡ ((a -> b) -> c)` — см. А11 |
| Существование | Связь `(b -> e)` существует тогда и только тогда, когда существуют `b` и `e` |
| Уникальность | Связь `(b -> e)` уникальна для пары `(b, e)` при фиксированном контексте |
| Направленность | Начало и конец различаются: `(b -> e) != (e -> b)` |

## Запреты

| Запрет | Причина |
|--------|---------|
| Транзитивность | Из `b -> e` и `e -> x` **не** следует `b -> x` |
| Перестановка | Нельзя менять местами начало и конец без инверсии |
| Самостоятельность `->` | `->` существует только как оператор, никогда как отдельная связь (константа) |

## Следствия

1. **Базовый конструктор** — `->` служит для построения всех сложных связей
2. **Структура направленности** — определяет фундаментальную асимметрию в МТС
3. **Различение по полюсам** — позволяет различать связи по их началу и концу

## Примеры применения

### Пример 1: Простая связь

```
∞ -> ∞
```

Связь акорня с акорнем (по А4 равна `∞`).

### Пример 2: Цепочка связей

```
a -> b -> c = (a -> b) -> c
```

По А11 (левоассоциативность) цепочка группируется слева направо.

### Пример 3: Вложенные связи

```
(a -> b) -> (c -> d)
```

Связь между двумя связями — начало есть связь `(a -> b)`, конец есть связь `(c -> d)`.

## Связь с нотациями

| Нотация | Представление |
|---------|---------------|
| Формальная | `a -> b` |
| Строковые ачисла | `(∞ -> 'a') -> 'b'` |
| Четверичная | `'[01]'` → цепочка абитов |

## Философское значение

> `->` создаёт новую целостность из начала и конца.

В МТС связь — не внешнее отношение между объектами, а фундаментальный способ порождения бытия. Оператор `->` выражает акт связывания: из двух смыслов возникает третья целостность.

Это основа онтологии МТС:
- Нет "объектов" вне связей
- Связь есть условие существования
- Направленность фундаментальна
