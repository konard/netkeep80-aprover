> **Статус:** Шаблон для будущего контента

> **Этап:** 5.3

## Формулы

```
x = x                           // Рефлексивность
(x = y) -> (y = x)              // Симметрия
{(x = y), (y = z)} -> (x = z)   // Транзитивность
```

## Краткое описание

Тождественность — отношение равенства в МТС с тремя свойствами.

## Планируемое содержание

1. Рефлексивность
2. Симметрия
3. Транзитивность
4. Дуальность символа `=`
