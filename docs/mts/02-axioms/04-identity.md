# А1: Аксиома тождественности

> **Статус:** Завершён
> **Источник:** `05-equality-duality.md`, `13-axiom-system.md`
> **Этап:** 5.3

## Формулы

```
// Рефлексивность
(x = x)

// Симметричность
((x = y) -> (y = x))

// Транзитивность
({ (x = y), (y = z) } -> (x = z))
```

## Содержательно-онтологическое определение

Связи тождественны, если их формы **неразличимы** в любом контексте. Тождественность не зависит от внешних критериев — только от внутренней структуры.

> Две связи тождественны тогда и только тогда, когда тождественны их конструкции.

## Дуальность символа `=`

Символ `=` в МТС не является простым обозначением «равенства» — он есть иконическое выражение двойственности бытия связи как **акта становления** и **факта бытия** одновременно.

### Вертикаль и горизонталь бытия

| Ось | Символ | Онтологический акт | Структурная роль |
|-----|--------|-------------------|------------------|
| Вертикальная | `->` | Порождение новой целостности | Акт связывания |
| Горизонтальная | `=` | Констатация неразличимости | Факт тождества |

### Почему `=` глубже `≡`

1. **Онтологическая экономия** — `=` содержит ровно две линии — минимальное выражение двойственности
2. **Иконичность формы** — горизонтальность линий отражает горизонтальный характер тождественности (сравнение «рядом»)
3. **Дуальность как принцип** — пустота между линиями есть условие различения и одновременно основание тождества

## Остенсивное определение

```
((a -> b) = (c -> d))
  ↓
{a = c, b = d}
```

Две связи структурно неразличимы, если неразличимы их компоненты.

## Структурные свойства

| Свойство | Формула | Описание |
|----------|---------|----------|
| Рефлексивность | `x = x` | Каждая связь тождественна себе |
| Симметричность | `(x = y) -> (y = x)` | Порядок не важен |
| Транзитивность | `{x = y, y = z} -> (x = z)` | Цепочка тождеств |
| Конгруэнтность | Тождественность под конструкторами | См. А2 |

## Структурная тождественность по конструкторам

```
// Для ->
((a -> b) = (c -> d)) -> {a = c, b = d}
{a = c, b = d} -> ((a -> b) = (c -> d))

// Для ♂
(♂a = ♂b) -> (a = b)
(a = b) -> (♂a = ♂b)

// Для ♀
(a♀ = b♀) -> (a = b)
(a = b) -> (a♀ = b♀)

// Для !
(!a = !b) -> (a = b)
(a = b) -> (!a = !b)
```

## Запреты

| Запрет | Причина |
|--------|---------|
| Внешние критерии тождественности | Только структура определяет тождество |
| Тождественность при различии компонентов | Хотя бы один компонент различен — связи различны |

## Следствия

1. **Все связи определяются формой** — нет "скрытых" свойств
2. **Единственность конструкций** — например, `∞` единственна
3. **Корректность сериализации** — ачисла однозначно представляют связи

## Примеры применения

### Пример 1: Рефлексивность

```
∞ = ∞
```

Прувер автоматически доказывает по А1.

### Пример 2: Симметричность

```
// Если доказано:
(♂∞ -> ∞♀) = 1

// То следует:
1 = (♂∞ -> ∞♀)
```

### Пример 3: Транзитивность

```
// Если доказано:
{a = b, b = c}

// То следует:
a = c
```

## Философское значение

> В МТС нет ничего кроме структуры.

Аксиома утверждает: две связи тождественны тогда и только тогда, когда тождественны их конструкции. Это исключает любую "онтологическую тень" за пределами форм связей.

Символ `=` в МТС — не техническое обозначение, а онтологический знак, чья форма непосредственно выражает суть тождественности: **неразличимость через структурированное различение**.
