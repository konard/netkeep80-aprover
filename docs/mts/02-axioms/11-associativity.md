# А11: Аксиома левоассоциативности

> **Статус:** Завершён
> **Источник:** `13-axiom-system.md`
> **Этап:** 5.3

## Формулы

```
(a -> b -> c) = ((a -> b) -> c)
(a -> (b -> c)) != ((a -> b) -> c)
```

## Содержательно-онтологическое определение

Аксиома фиксирует **единственно допустимый порядок группировки** последовательностей связей — левоассоциативный.

> Это не алгебраическое свойство, а **онтологический принцип конструирования**: каждая новая связь присоединяется к результату предыдущего акта связывания.

## Остенсивное определение

```
a -> b -> c
  ↓
((a -> b) -> c)
```

Слева направо: сначала `a -> b`, затем результат связывается с `c`.

## Структурные свойства

| Свойство | Формула | Описание |
|----------|---------|----------|
| Левоассоциативность | `abc ≡ ((a -> b) -> c)` | Без скобок — слева направо |
| Неравенство | `a(bc) ≠ abc` | Правая группировка отличается |
| Явные скобки | `a -> (b -> c)` | Скобки переопределяют порядок |
| Цепочка | `a₁a₂...aₙ = (...((a₁ -> a₂) -> a₃) ...) -> aₙ` | Общая формула |

## Ключевые различия

### Левоассоциативная группировка (по умолчанию)

```
a -> b -> c = (a -> b) -> c

Структура:
    (a -> b)
        \
         \
          c
```

### Правоассоциативная группировка (явные скобки)

```
a -> (b -> c)

Структура:
    a
     \
      \
       (b -> c)
```

**Важно:** `(a -> b) -> c ≠ a -> (b -> c)` — это **разные связи**!

## Запреты

| Запрет | Причина |
|--------|---------|
| `abc` как `a -> (b -> c)` | Нарушает порядок конструирования |
| Внешние правила композиции | МТС не является категорией |
| Транзитивность | Из `a -> b` и `b -> c` **не** следует `a -> c` |

## Следствия

1. **Однозначная интерпретация** — любая последовательность без скобок имеет единственное прочтение
2. **Иерархические структуры** — явные скобки позволяют строить вложенные структуры
3. **Сериализация** — однозначность сериализации/десериализации ачисел

## Примеры применения

### Пример 1: Простая цепочка

```
∞ -> ∞ -> ∞ = ((∞ -> ∞) -> ∞) = (∞ -> ∞) = ∞
```

По А4 и А11 сворачивается в `∞`.

### Пример 2: Строковое ачисло

```
"ab" = ∞ -> 'a' -> 'b' = ((∞ -> 'a') -> 'b')
```

Каждый символ присоединяется слева направо.

### Пример 3: Явная группировка

```
∞ -> (♂∞ -> ∞♀) = ∞ -> 1
```

Скобки явно указывают, что `1 = (♂∞ -> ∞♀)` — отдельная связь.

### Пример 4: Различие группировок

```
a -> b -> c  ≠  a -> (b -> c)

// Слева: ((a -> b) -> c)
// Справа: (a -> (b -> c))
```

Разные структуры, разные связи.

## Связь с синтаксисом

### Ассоциативность операторов

| Оператор | Ассоциативность | Пример |
|----------|-----------------|--------|
| `->` | Левая | `abc = ((a -> b) -> c)` |
| `♂` | Правая | `♂♂v = ♂(♂v)` |
| `♀` | Левая | `r♀♀ = (r♀)♀` |
| `!` | Правая | `!!x` — нет проблемы (унарный) |

### EBNF грамматика

```ebnf
Chain ::= Pref { LinkOp Pref } ;   // левоассоциативность задаётся парсером
LinkOp ::= "->" | "!->" ;
```

Парсер группирует `->` слева направо.

## Реализация в коде

```typescript
// src/core/prover.ts:122-127
A11: {
  id: 'A11',
  name: 'Левоассоциативность',
  formula: '(a → b → c) = ((a → b) → c)',
  description: 'Порядок группировки',
},

// src/core/parser.ts
// Парсинг цепочки связей (левоассоциативно)
function parseChain(): ASTNode {
  let left = parsePref()
  while (match(TOKEN.ARROW) || match(TOKEN.NEG_ARROW)) {
    const op = previous()
    const right = parsePref()
    left = { type: 'Link', left, right }  // левоассоциативность
  }
  return left
}
```

### Функции парсера

| Функция | Назначение |
|---------|------------|
| `parseChain()` | Парсинг цепочки с левой ассоциативностью |
| `parsePref()` | Парсинг префиксных операторов (♂, !) |
| `parsePost()` | Парсинг постфиксных операторов (♀) |

## Философское значение

> Структура строится последовательно слева направо.

Левоассоциативность — не произвольное соглашение, а отражение онтологического принципа:
- Каждая новая связь присоединяется к **уже построенному целому**
- Порядок конструирования **фиксирует смысл**
- МТС есть **онтологически направленная система**

Это делает сериализацию однозначной и позволяет читать ачисла как последовательности актов связывания.
