## Краткое описание

Абиты — четверичная система символов для сериализации связей.

## Планируемое содержание

1. Четыре абита: `[`, `]`, `1`, `0`
2. Связь с единицей и нулём смысла
3. Четверичная нотация .anum
4. Примеры
