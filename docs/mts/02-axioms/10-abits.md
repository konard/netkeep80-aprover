# А10: Аксиома абитов

> **Статус:** Завершён
> **Источник:** `13-axiom-system.md`
> **Этап:** 5.3

## Формулы

```
'[' : ♂∞     // Начальный смысл
']' : ∞♀     // Конечный смысл
'1' : 1      // Истина
'0' : 0      // Ложь
```

## Содержательно-онтологическое определение

Четыре базовых **абита** (ассоциативных бита) определяют четыре элементарные формы связей вокруг акорня, соответствующие четырём ассоциативным состояниям алогики.

Абиты служат для **сериализации связей** в компактные последовательности — ачисла.

## Таблица соответствия

| Абит | Форма МТС | Онтологический смысл | Описание |
|------|-----------|---------------------|----------|
| `[` | `♂∞` | Начальный смысл | Самозамкнутое начало относительно `∞` |
| `]` | `∞♀` | Конечный смысл | Самозамкнутый конец относительно `∞` |
| `1` | `♂∞ -> ∞♀` | Истина | Наличие направленной связи |
| `0` | `∞♀ -> ♂∞` | Ложь | Инверсия связи |

## Остенсивное определение

```
[   ]   1   0
↓   ↓   ↓   ↓
♂∞  ∞♀  1   0
```

Четыре символа визуально отражают четыре базовые формы.

## Структурные свойства

| Свойство | Описание |
|----------|----------|
| Количество | Ровно 4 символа: `0`, `1`, `[`, `]` |
| Исключение `∞` | `∞` не является абитом и не входит в четверичные ачисла |
| UTF-8 представление | Любой символ UTF-8 может быть представлен как последовательность абитов |
| Логические значения | `1` и `0` соответствуют истине и ложности |
| Контексты | `[` и `]` образуют вложенные контексты |

## Четверичная (абитовая) нотация

### Алфавит

Четверичная нотация использует ровно 4 символа:
- `0` — нуль смысла
- `1` — единица смысла
- `[` — начало контекста (начало смысла)
- `]` — конец контекста (конец смысла)

### Вложенные контексты

```
01010001[010100[1001]010]
```

Квадратные скобки создают вложенные контексты внутри ачисла.

### Конвертация в формальную нотацию

```
'01[]' → ∞ -> 0 -> 1 -> ♂∞ -> ∞♀
      = ∞ -> (∞♀ -> ♂∞) -> (♂∞ -> ∞♀) -> ♂∞ -> ∞♀
```

Каждый абит последовательно связывается с предыдущим.

## Запреты

| Запрет | Причина |
|--------|---------|
| Другие символы как абиты | Только `0`, `1`, `[`, `]` |
| Смешение доменов | Абиты не используются как операторы в формальной нотации |
| `()` в абитовой нотации | Только `[` и `]` для контекстов |
| `∞` в ачислах | `∞` — мета-уровень, не абит |

## Следствия

1. **Полная сериализация** — любая связь может быть представлена как последовательность абитов
2. **Эффективная апамять** — создание структур данных на основе абитов
3. **4-значная алогика** — построение логики на четырёх базовых значениях
4. **Мост к реализации** — связь между абстрактными формами и конкретным представлением

## Примеры применения

### Пример 1: Простое ачисло

```
'1' = 1 = (♂∞ -> ∞♀)
```

Абит `1` эквивалентен единице смысла.

### Пример 2: Пара абитов

```
'01' → ∞ -> 0 -> 1
     = ∞ -> (∞♀ -> ♂∞) -> (♂∞ -> ∞♀)
```

### Пример 3: Контекст

```
'[01]' → ∞ -> ♂∞ -> 0 -> 1 -> ∞♀
```

Контекст, содержащий `01`.

### Пример 4: Вложенный контекст

```
'[[]]' → ∞ -> ♂∞ -> ♂∞ -> ∞♀ -> ∞♀
```

Двойное вложение контекста.

## Философское значение

> Абиты — компактные представления элементарных форм связей.

Аксиома А10 определяет четыре базовых абита как "атомы" для построения любых структур данных. Это не часть формального ядра МТС, а инструмент для практичной реализации:

- `[` и `]` — границы контекста (начало/конец)
- `1` и `0` — направление связи (присутствие/инверсия)

Через абиты МТС обретает конкретную форму сериализации, сохраняя онтологическую чистоту.
