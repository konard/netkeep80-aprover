# А4: Акорень ∞

> **Статус:** Завершён
> **Источник:** `03-aroot-foundation.md`, `13-axiom-system.md`
> **Этап:** 5.3

## Формула

```
∞ : (∞ -> ∞)
```

## Содержательно-онтологическое определение

Символ `∞` определяет запрос ко всем связям, удовлетворяющим форме **полного самозамыкания** `x = x -> x`. Это единственная форма, где начало и конец полностью совпадают.

> **Аксиома смысла:** Полностью самозамкнутая форма связи есть смысл, и он определяется связью смыслов.

### Ключевые принципы

| Принцип | Описание |
|---------|----------|
| **Нульарный квантор** | `∞` не конструируется из начала и конца, а **порождает саму возможность их различения** |
| **Неразложимая целостность** | `∞ = ∞ -> ∞` — не бесконечная регрессия, а синхронный акт самоопределения |
| **Условие возможности** | Без `∞` оператор `->` не имел бы "где" действовать |

## Остенсивное определение

```
∞
↓
┌───────┐
│       ↓
└───────┘
```

Графическая форма `∞` остенсивно отображает полное самозамыкание без различимых начала и конца.

## Структурные свойства

| Свойство | Формула | Описание |
|----------|---------|----------|
| Нульарность | `∞` не имеет аргументов | Базовая константа системы |
| Самоопределение | `∞ = ∞ -> ∞` | По определению |
| Идемпотентность | Для любого `n ≥ 1`: `∞ⁿ = ∞` | Повторное связывание не меняет `∞` |
| Единственность | `(x = x -> x) -> (x = ∞)` | Теорема единственности акорня |
| Самодуальность | `!∞ = ∞` | Инварианта относительно инверсии |

## Порождение базовых форм

Из недифференцированной целостности `∞` возникают четыре базовые формы через акты связывания с самим собой:

| Форма | Определение | Описание |
|-------|-------------|----------|
| `♂∞` | `(♂∞ -> ∞)` | Начало смысла — самозамыкание по началу |
| `∞♀` | `(∞ -> ∞♀)` | Конец смысла — самозамыкание по концу |
| `1` | `(♂∞ -> ∞♀)` | Направленность — связь начала с концом |
| `0` | `(∞♀ -> ♂∞)` | Инверсия направленности |

### Различение начала и конца

- В `♂∞` начало замкнуто на себя (через ∞), конец — ∞ → возникает смысл «начала»
- В `∞♀` начало — ∞, конец замкнут на себя (через ∞) → возникает смысл «конца»

## Запреты

| Запрет | Причина |
|--------|---------|
| `∞` не является "фоном" | Это универсальная связь, способная исполнять любой смысл |
| `∞` не есть "бесконечная цепочка" | Это неразложимая целостность |
| `∞` не получается из других конструкций | Это фундаментальная константа |
| `∞` не входит в состав ачисел как абит | Только на мета-уровне |

## Следствия

1. **Базис существования** — `∞` служит основой для существования: без неё оператор `->` не имел бы "где" действовать
2. **Порождение абитов** — `∞` порождает 4 абита через 4 базовые связи вокруг акорня
3. **Сериализация** — `∞` обеспечивает возможность сериализации всех других связей
4. **Неявное начало** — Любое ачисло неявно начинается с `∞` как точки начала последовательности

## Примеры применения

### Пример 1: Раскрытие `∞`

```
∞ = ∞ -> ∞
```

Прувер применяет А4 для раскрытия или свёртывания `∞`.

### Пример 2: Цепочка `∞`

```
((∞ -> ∞) -> ∞) = ∞
```

По А4 и А11 (левоассоциативность), цепочка любой длины из `∞` сводится к `∞`.

### Пример 3: Построение смысла

```
смысл(b -> e) = (♂∞ -> b) -> (e -> ∞♀)
```

Смысл любой связи определяется через её отношение к `∞`.

## Связь с другими аксиомами

| Аксиома | Связь |

| А5, А6 | `♂∞` и `∞♀` — частичные самозамыкания относительно `∞` |

| А8, А9 | `1 : (♂∞ -> ∞♀)`, `0 : !1` — производные от `∞` |

## Философское значение

> `∞` — условие возможности различения, а не результат различения.

Это принципиально: `∞` не выводится из других аксиом, потому что без условия возможности акт связывания невозможен. `∞` есть нульарный квантор существования: он не конструируется из начала и конца, а **порождает саму возможность их различения**.
