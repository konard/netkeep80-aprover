## Формула

```
(s : F) -> (s = F)
```

## Краткое описание

Определение (`:`) — онтологический акт, связывающий знак с формой.

## Планируемое содержание

1. Семантика оператора `:`
2. Связь с запросами по форме
3. Примеры определений
