# А0: Аксиома определения

> **Статус:** Завершён
> **Источник:** `04-definition-axiom.md`, `13-axiom-system.md`
> **Этап:** 5.3

## Формула

```
(s : F) -> (s = F)
```

## Содержательно-онтологическое определение

Символ `s` вводится не как ссылка на связь, а как **запрос ко всем связям**, удовлетворяющим форме `F`. Акт определения порождает структурную тождественность между именем и формой.

> Знак не «ссылается» на связь — он **задаёт паттерн различения формы**.

## Онтологическое различение `:` и `=`

| Оператор | Онтологический статус | Природа | Направленность |
|----------|----------------------|---------|----------------|
| `:` | **Акт различения формы** | Процесс установления соответствия между знаком и паттерном | Ориентирован: `(s : F) != (F : s)` |
| `=` | **Факт структурной тождественности** | Констатация неразличимости двух связей по форме | Симметричен: `s = F ⇔ F = s` |

## Остенсивное определение

```
s : F
 ↓
s = F
```

Графически: связь от запроса к форме его удовлетворения.

## Структурные свойства

| Свойство | Формула | Описание |
|----------|---------|----------|
| Ориентированность | `(s : F) != (F : s)` | Определение направлено от знака к форме |
| Единственность | `{s : F, s : G} -> (F = G)` | Один знак определяет одну форму |
| Guarded recursion | Рекурсия только под `->` | Рекурсивное определение защищено конструктором |
| Порождение тождества | `(s : F) -> (s = F)` | Определение влечёт тождество |

## Почему `:` всегда влечёт `=`, но не наоборот

**Направленность `:` против симметрии `=`:**

```
(s : F) != (F : s)   // определение ориентировано
но
(s = F) ⇔ (F = s)    // тождественность симметрична
```

**`=` может возникать без `:`:**

1. **Через вывод из других аксиом:**
   ```
   ♂∞ = (♂∞ -> ∞)       // из аксиомы А5
   ∞♀ = (∞ -> ∞♀)       // из аксиомы А6
   ```

2. **Через унификацию компонентов:**
   ```
   ((a -> b) = (c -> d)) -> { a = c, b = d }  // аксиома декомпозиции
   ```

3. **Через инверсию:**
   ```
   (a = b) -> (!a = !b)  // конгруэнтность инверсии
   ```

## Запреты

| Запрет | Причина |
|--------|---------|
| Определение через внешние понятия | "объект", "мир" — внешние концепции |
| Введение символа без формы запроса | Каждый знак должен иметь форму |
| Неограждённая рекурсия | Рекурсия только под конструктором `->` |

## Следствия

1. **Устранение разрыва "знак ↔ связь"** — знак становится оператором различения формы
2. **Рекурсивные конструкции** — возможность введения `♂`, `♀`, `∞` как запросов по форме
3. **Онтологическая чистота** — нет внешних объектов, только паттерны связей

## Примеры применения

### Пример 1: Определение акорня

```
∞ : (∞ -> ∞)
```

Знак `∞` определяется как запрос к форме полного самозамыкания.

### Пример 2: Определение самозамыкания начала

```
♂x : (♂x -> x)
```

Знак `♂x` определяется как запрос к форме, где начало замкнуто на саму связь.

### Пример 3: Определение единицы смысла

```
1 : (♂∞ -> ∞♀)
```

Знак `1` определяется как направленная связь между началом и концом смысла.

## Философское значение

> Аксиома устанавливает знак как паттерн различения в "океане связей", а не как мост к внешнему миру.

Это фундамент онтологической чистоты МТС:
- Акт определения `:` есть **достаточное условие** для возникновения `=`, но не необходимое
- Тождественность может порождаться и другими онтологическими актами (вывод, унификация, инверсия)
- Две горизонтальные черты `=` визуально выражают двойственность: две неразличимые связи, лежащие «рядом» в онтологическом поле
