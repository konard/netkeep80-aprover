# А8-А9: Единица и нуль смысла

> **Статус:** Завершён
> **Источник:** `13-axiom-system.md`
> **Этап:** 5.3

## Формулы

```
1 : (♂∞ -> ∞♀)    // А8: Единица смысла
0 : !1            // А9: Нуль смысла
```

## Содержательно-онтологическое определение

### А8: Единица смысла (1)

Символ `1` определяет запрос ко всем связям, удовлетворяющим форме связи между **началом смысла** (`♂∞`) и **концом смысла** (`∞♀`). Это базовая единица направленной связи — минимальная структура, в которой возникает различение начала и конца.

### А9: Нуль смысла (0)

Символ `0` определяется как инверсия единицы. Это связь в противоположном направлении — от конца к началу смысла.

```
0 = !1 = !(♂∞ -> ∞♀) = (∞♀ -> ♂∞)
```

## Остенсивное определение

### Единица (1)

```
1
↓
♂∞ -> ∞♀
 ↓       ↓
начало  конец
```

Направленная связь от начала смысла к концу смысла.

### Нуль (0)

```
0
↓
∞♀ -> ♂∞
 ↓       ↓
конец  начало
```

Инверсия направления — от конца к началу.

## Структурные свойства

| Свойство | Формула | Описание |
|----------|---------|----------|
| Константность | `1`, `0` — нульарные операторы | Не имеют аргументов |
| Дуальность | `0 = !1`, `1 = !0` | Взаимная выразимость через инверсию |
| Различимость | `1 != 0` | Единица не равна нулю |
| Раскрытие `1` | `1 = (♂∞ -> ∞♀)` | По определению |
| Раскрытие `0` | `0 = (∞♀ -> ♂∞)` | Через инверсию |

## Связь с 4-значной логикой

В МТС существует 4-значная алогика, основанная на четырёх базовых формах вокруг `∞`:

| Значение | Форма | Абит | Описание |
|----------|-------|------|----------|
| Начало смысла | `♂∞` | `[` | Самозамкнутое начало |
| Конец смысла | `∞♀` | `]` | Самозамкнутый конец |
| Истина | `1 = (♂∞ -> ∞♀)` | `1` | Наличие направленной связи |
| Ложь | `0 = (∞♀ -> ♂∞)` | `0` | Отсутствие/инверсия связи |

## Запреты

| Запрет | Причина |
|--------|---------|
| `1` без начала и конца | Единица обязательно имеет направленность |
| `1 = ∞` | Единица — не полное самозамыкание |
| `1` как "объект" | Это связь, не внешний объект |

## Следствия

1. **Минимальная направленная структура** — `1` определяет наименьшую структуру с различением полюсов
2. **Основа алогики** — `1` и `0` служат базисом для построения 4-значной логики МТС
3. **Логические операции** — возможность определения через структуру связей
4. **Абиты** — `'1' : 1`, `'0' : 0` — сериализация в четверичную систему

## Примеры применения

### Пример 1: Раскрытие единицы

```
1 = (♂∞ -> ∞♀)
```

Прувер раскрывает `1` по определению.

### Пример 2: Связь с нулём

```
!1 = !(♂∞ -> ∞♀) = (∞♀ -> ♂∞) = 0
```

Инверсия единицы даёт нуль.

### Пример 3: Двойная инверсия

```
!!1 = !0 = 1
```

Двойная инверсия возвращает исходное значение.

### Пример 4: Построение ачисла

```
∞ -> 1 -> 0 = ∞ -> (♂∞ -> ∞♀) -> (∞♀ -> ♂∞)
```

Цепочка из единицы и нуля в формальной нотации.

## Философское значение

> `1` — минимальная структура смысловой направленности.

Единица и нуль в МТС — не абстрактные числа, а фундаментальные формы связей:
- **`1`** — направленная связь от начала к концу смысла, "присутствие" различения
- **`0`** — инверсия направления, "инверсия" различения (не отсутствие!)

Это основа для построения алогики и вычислительных конструкций в МТС.
