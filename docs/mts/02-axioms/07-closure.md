# А5-А6: Самозамыкание

> **Статус:** Шаблон для будущего контента
> **Этап:** 5.3

## Формулы

```
♂x : (♂x -> x)    // А5: Самозамыкание начала
x♀ : (x -> x♀)    // А6: Самозамыкание конца
```

## Краткое описание

Самозамыкание — начало (♂) и конец (♀) замкнуты на связь.

## Планируемое содержание

1. Символ ♂ (Male) — начало
2. Символ ♀ (Female) — конец
3. Связь с инверсией
4. Примеры

## Реализация

```typescript
// src/core/prover.ts

  name: 'Самозамыкание начала',
  formula: '♂x : (♂x -> x)',

  name: 'Самозамыкание конца',
  formula: 'x♀ : (x -> x♀)',
  description: 'Конец замкнут на связь'
}
```
