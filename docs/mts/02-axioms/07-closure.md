# А5-А6: Аксиомы самозамыкания

> **Статус:** Завершён
> **Источник:** `13-axiom-system.md`
> **Этап:** 5.3

## Формулы

```
♂x : (♂x -> x)    // А5: Самозамыкание начала
x♀ : (x -> x♀)    // А6: Самозамыкание конца
```

## Содержательно-онтологическое определение

### А5: Самозамыкание начала (♂)

Символ `♂x` определяет запрос ко всем связям, удовлетворяющим форме **самозамыкания по началу** `y = y -> x`. Отсутствие начала (самозамыкание начала) означает, что связь использует себя в качестве своего же начала, а конец — внешняя связь `x`.

### А6: Самозамыкание конца (♀)

Символ `x♀` определяет запрос ко всем связям, удовлетворяющим форме **самозамыкания по концу** `y = x -> y`. Отсутствие конца (самозамыкание конца) означает, что связь использует себя в качестве своего же конца, а начало — внешняя связь `x`.

## Остенсивное определение

### ♂x (Male — начало)

```
♂x
↓
  ┌───┐
  │   ↓
  y -> x
```

Графическая форма `♂` остенсивно отображает замыкание начала на саму связь.

### x♀ (Female — конец)

```
x♀
↓
x -> y
    ↓
    └───┘
```

Графическая форма `♀` остенсивно отображает замыкание конца на саму связь.

## Структурные свойства

### А5 (♂)

| Свойство | Формула | Описание |
|----------|---------|----------|
| Префиксность | `♂` — префиксный оператор | Записывается перед операндом |
| Правоассоциативность | `♂♂v ≡ ♂(♂v)` | Вложенное самозамыкание |
| Инъективность | `♂a = ♂b ⇔ a = b` | Различные аргументы дают различные результаты |
| Дуальность | `!(♂x) = x♀` | Связь с инверсией |

### А6 (♀)

| Свойство | Формула | Описание |
|----------|---------|----------|
| Постфиксность | `♀` — постфиксный оператор | Записывается после операнда |
| Левоассоциативность | `r♀♀ ≡ (r♀)♀` | Вложенное самозамыкание |
| Инъективность | `a♀ = b♀ ⇔ a = b` | Различные аргументы дают различные результаты |
| Дуальность | `!(x♀) = ♂x` | Связь с инверсией |

## Связь ♂ и ♀ через инверсию

```
!(♂x) = x♀
!(x♀) = ♂x
```

Операторы `♂` и `♀` дуальны друг другу относительно инверсии `!`.

## Теорема: Слияние рекурсий

```
♂♀ = ∞
```

**Доказательство:**
1. По А5: `♂♀ = (♂♀ -> ♀)`
2. По А6: `♂♀ = (♂ -> ♂♀)`
3. Из (1) и (2): начало `♂♀ = ♂♀`, конец `♂♀ = ♂♀`
4. Следовательно: `♂♀ = (♂♀ -> ♂♀)`
5. По А4 и А2: связь формы `x = x -> x` единственна и есть `∞`
6. Поэтому: `♂♀ = ∞`

**Смысл:** Полное слияние рекурсий по началу и концу порождает ассоциативный корень.

## Запреты

| Запрет | Причина |
|--------|---------|
| `♂x` как "рекурсивная функция" | Это не процесс, а паттерн поиска |
| `♂x = ∞` для любого `x` | Частичное замыкание ≠ полному |
| Внешняя реализация замыкания | Только через конструкторы `♂` и `♀` |

## Следствия

1. **Устранение регрессии** — нет бесконечной регрессии при определении самоссылающихся структур
2. **Базовые элементы** — `♂∞` и `∞♀` как начало и конец смысла
3. **Различение** — определяется смысл "начала" и "конца" в контексте связей
4. **Порождение абитов** — `'[' : ♂∞`, `']' : ∞♀`

## Примеры применения

### Пример 1: Раскрытие ♂∞

```
♂∞ = (♂∞ -> ∞)
```

Прувер применяет А5 для раскрытия.

### Пример 2: Раскрытие ∞♀

```
∞♀ = (∞ -> ∞♀)
```

Прувер применяет А6 для раскрытия.

### Пример 3: Единица смысла

```
1 : (♂∞ -> ∞♀)
```

Единица определяется как связь между началом и концом смысла.

## Философское значение

> `♂` и `♀` — остенсивные иконические знаки, форма которых выражает структуру самозамыкания.

Аксиомы вводят конструкторы замыкания как паттерны поиска в "океане связей". Это не рекурсивные определения в классическом смысле, а способы различения форм связей с частичным самозамыканием.

Графические символы `♂` и `♀` визуально отражают асимметрию: замкнутое начало vs замкнутый конец.
