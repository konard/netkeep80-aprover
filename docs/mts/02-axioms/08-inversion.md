# А7: Инверсия

> **Статус:** Шаблон для будущего контента
> **Этап:** 5.3

## Формулы

```
!(a -> b) = (b -> a)    // Инверсия связи
!(♂x) = x♀              // Инверсия начала
!(x♀) = ♂x              // Инверсия конца
!∞ = ∞                  // Инверсия акорня
!!x = x                 // Двойная инверсия
```

## Краткое описание

Инверсия (`!`) — дуальность, обращение направления связи.

## Планируемое содержание

1. Семантика оператора `!`
2. Инверсия и дуальность
3. Связь с нулём смысла (0 = !1)
4. Примеры
