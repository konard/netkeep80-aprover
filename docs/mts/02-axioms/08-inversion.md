# А7: Аксиома инверсии/дуальности

> **Статус:** Завершён
> **Источник:** `13-axiom-system.md`
> **Этап:** 5.3

## Формулы

```
// Инверсия направленности связи
!(a -> b) = (b -> a)
!(a !-> b) = (b !-> a)

// Дуальность самозамыканий
!(♂x) = x♀
!(x♀) = ♂x

// Самодуальность акорня
!∞ = ∞

// Инволюция
!!x = x
```

## Содержательно-онтологическое определение

Оператор инверсии `!` (синоним `¬`) меняет местами начало и конец в направленной связи, создавая новую связь с обратной ориентацией.

> Инверсия — это не отрицание существования, а **переконфигурация структуры** — онтологическая симметрия, заложенная в саму ткань МТС.

## Остенсивное определение

```
!(a -> b)
  ↓
  b
   \
    \
     a
```

Графическая форма `!` остенсивно отображает изменение направления стрелки.

## Структурные свойства

| Свойство | Формула | Описание |
|----------|---------|----------|
| Унарность | `!` — унарный оператор | Применяется к одному операнду |
| Правоассоциативность | `!!x = x` | Двойная инверсия возвращает исходное |
| Инволютивность | `!!a = a` | Самообратимость |
| Контравариантность | `!(a -> b) = (!b -> !a)` | Инверсия сохраняет структуру |
| Сохранение тождества | `a = b ⇔ !a = !b` | Конгруэнция по `!` |

## Ключевые тождества

### Инверсия связи

```
!(a -> b) = (b -> a)
```

Меняет местами начало и конец.

### Дуальность ♂ и ♀

```
!(♂x) = x♀
!(x♀) = ♂x
```

Самозамыкание начала дуально самозамыканию конца.

### Самодуальность ∞

```
!∞ = ∞
```

Акорень инвариантен относительно инверсии — единственная такая связь.

### Определение 0 через инверсию

```
0 : !1
```

Нуль смысла есть инверсия единицы.

## Запреты

| Запрет | Причина |
|--------|---------|
| `!a` как "несуществование" | Даже `!1` есть существующая связь (`0`) |
| `!` к абитам напрямую | Инверсия применяется к формам связей |
| `!a` как "отсутствие a" | Это переориентация, не отрицание |

## Следствия

1. **Определение логических констант** — `1 : (♂∞ -> ∞♀)`, `0 : !1`
2. **Взаимная выразимость** — `♂x = !(x♀)`, `x♀ = !(♂x)`
3. **Обратный поиск** — возможность обратного поиска в апамяти
4. **Онтологическая полнота** — через симметрию каждая структура имеет дуальную форму

## Примеры применения

### Пример 1: Инверсия простой связи

```
!(♂∞ -> ∞♀) = (∞♀ -> ♂∞) = 0
```

Инверсия единицы даёт нуль.

### Пример 2: Двойная инверсия

```
!!∞ = !∞ = ∞
```

Акорень самодуален, двойная инверсия возвращает его же.

### Пример 3: Дуальность самозамыкания

```
!(♂∞) = ∞♀
```

Начало смысла дуально концу смысла.

## Нотация !->

Токен `!->` — синтаксический сахар для "отрицания стрелки":

```
(a !-> b) = !(a -> b)
```

В ядре прувера `!->` нормализуется в `!(a -> b)`.

## Философское значение

> Инверсия не разрушает, а **переориентирует** связь.

Оператор `!` выражает онтологическую симметрию МТС. Каждая структура имеет свою двойственную форму. Это не логическое отрицание (нет "несуществования"), а внутренняя симметрия направленных связей.

Инверсия делает МТС онтологически замкнутой: меняя местами смыслы начала и конца, мы остаёмся в пространстве связей.
