## Онтологический фундамент

МТС есть онтологически замкнутая система, в которой **всё есть связь**. Знак не ссылается на внешний объект — знак есть запрос по форме, определяющий паттерн различения в асети связей.

| Принцип | Формулировка |
|---------|--------------|
| Существование | = связывание |
| Определение | = запрос по форме |
| Смысл | = структура связи |

## Логическая иерархия аксиом

### Уровень 0: Фундамент
- **А4 (Акорень)** — условие возможности различения, нульарный квантор существования

### Уровень 1: Базовые конструкторы
- **А3 (Связь)** — бинарный оператор создания связи
- **А5, А6 (Самозамыкание)** — унарные операторы замыкания по началу/концу
- **А7 (Инверсия)** — унарный оператор переориентации

### Уровень 2: Метаструктура
- **А0 (Определение)** — акт различения формы
- **А1 (Тождественность)** — структурная неразличимость
- **А2 (Конгруэнция)** — сохранение тождества под конструкторами
- **А11 (Левоассоциативность)** — порядок группировки

### Уровень 3: Производные константы
- **А8, А9 (Семантика)** — единица и нуль смысла
- **А10 (Абиты)** — четверичная система сериализации

## Предварительные соглашения

### Уровни языка

| Уровень | Статус | Символы |
|---------|--------|---------|
| **Объектный язык** | Внутренние связи асети | `∞`, `->`, `!->`, `♂`, `♀`, `!`, `[`, `]`, `0`, `1` |
| **Формальная нотация** | Запросы по форме связей | `:`, `=`, `!=`, `{}`, `(`, `)` (только для группировки) |
| **Метаязык** | Описание системы (внешний) | Слова на русском, `⇒`, `⇔` |

### Синтаксические соглашения

| Правило | Описание | Пример |
|---------|----------|--------|
| Левоассоциативность `->` | `abc ≡ ((a -> b) -> c)` | `∞∞∞ = ((∞ -> ∞) -> ∞)` |
| Правоассоциативность `♂` | `♂♂v ≡ ♂(♂v)` | `♂♂∞ = ♂(♂∞)` |
| Левоассоциативность `♀` | `r♀♀ ≡ (r♀)♀` | `∞♀♀ = (∞♀)♀` |
| Скобки группировки | Явное переопределение порядка | `a(bc) ≠ abc` |
| Пакет `{}` | Контейнер множества выражений | `{A, B} ≡ {B, A}` |

### Терминологическая чистота

| Запрещено | Разрешено |
|-----------|-----------|
| роль | смысл |
| ссылка/значение | начало/конец |
| различие | смысл |
| объект, свойство | связь, форма связи |
| множество, тип, категория | асеть, паттерн формы |

## Фундаментальные теоремы

### Теорема 1: Слияние рекурсий

**Формула:** `♂♀ = ∞`

**Доказательство:**
1. По А5: `♂♀ = (♂♀ -> ♀)`
2. По А6: `♂♀ = (♂ -> ♂♀)`
3. Из (1) и (2): начало `♂♀ = ♂♀`, конец `♂♀ = ♂♀`
4. Следовательно: `♂♀ = (♂♀ -> ♂♀)`
5. По А4 и А2: связь формы `x = x -> x` единственна и есть `∞`
6. Поэтому: `♂♀ = ∞`

**Смысл теоремы:** Полное слияние рекурсий по началу и концу порождает ассоциативный корень.

## Онтологическая чистота системы

| Критерий | Статус |
|----------|--------|
| Нет внешних понятий | ✅ все символы — запросы по форме связей |
| Самодостаточность | ✅ нотация описывает саму себя через запросы по форме |
| Отсутствие онтологических теней | ✅ каждый символ имеет явную форму связи |
| Иконичность | ✅ форма символа отражает структуру запроса |
| Конструктивность | ✅ символы не описывают, а конструируют запросы по форме |
