# Строковые ачисла (.astr)

> **Статус:** Завершён
> **Источники:** `07-three-notations.md`, `specification/v0.1.md`
> **Этап:** 5.4

## Назначение

Строковые ачисла — человекочитаемая форма сериализации связей. Представляют произвольные данные (включая тексты на естественных языках и саму формальную нотацию) как последовательности связей.

| Характеристика | Значение |
|----------------|----------|
| Расширение файлов | `.astr` (Associative STRing) |
| Алфавит | Любой UTF-8 символ |
| Онтологический статус | Конкретные связи-последовательности в асети |
| Область применения | Человекочитаемость, интеграция с текстовыми данными |

## Что такое строковое ачисло?

Строковое ачисло — это **не** «строка текста», а **конкретная связь** в асети, имеющая форму последовательного связывания. Каждый символ — уже связь со своим смыслом.

### Онтологический статус

| Понятие | Традиционное понимание | В МТС |
|---------|------------------------|-------|
| Строка | Последовательность символов | Связь-последовательность в асети |
| Символ | Элемент алфавита | Запрос по форме связи |
| Кодирование | Преобразование данных | Акт связывания |

## Принцип кодирования

### Шаг 1: Ввод символа через определение

Каждый символ UTF-8 `c` вводится через акт определения в формальной нотации:

```mtl
'c' : T_c
```

где `T_c` — терм, задающий форму связи для символа `c`.

### Шаг 2: Левоассоциативная композиция

Строка `c₁c₂...cₙ` интерпретируется как левоассоциативная цепочка связей:

```
(((∞ -> 'c₁') -> 'c₂') -> ... -> 'cₙ')
```

### Пример

Строковое ачисло `"связь"` интерпретируется как:

```
"связь" ≡ (((((∞ -> 'с') -> 'в') -> 'я') -> 'з') -> 'ь')
```

## Графическое представление

```
∞ ──→ 'с' ──→ 'в' ──→ 'я' ──→ 'з' ──→ 'ь'
│     │      │      │      │      │
└─────┴──────┴──────┴──────┴──────┘
       "связь" (строковое ачисло)
```

## Формат файла .astr

### Синтаксис

```
// Комментарии поддерживаются (от // до конца строки)

связь
link
Hello, мир!
🌍🔗✨
```

### Правила

| Правило | Описание |
|---------|----------|
| Каждая строка | Отдельное строковое ачисло |
| Комментарии | `//` до конца строки |
| Пустые строки | Игнорируются |
| UTF-8 | Полная поддержка (включая эмодзи) |

### Пример файла

```astr
// Примеры строковых ачисел

// Русский текст
связь
акорень

// Английский текст
link
connection

// Смешанный текст
Hello, мир!

// Эмодзи и специальные символы
🌍🔗✨
≡→↔

// Формальная нотация как строка
♂∞ -> ∞♀
```

## Конвертация в формальную нотацию

### Алгоритм

1. Каждая строка файла `.astr` конвертируется в формальное выражение
2. Каждый символ становится связью с акорнем
3. Последовательность символов образует цепочку связей

### Пример конвертации

| Вход (.astr) | Выход (.mtl) |
|--------------|--------------|
| `A` | `(∞ -> 'A')` |
| `AB` | `((∞ -> 'A') -> 'B')` |
| `связь` | `(((((∞ -> 'с') -> 'в') -> 'я') -> 'з') -> 'ь')` |

## Визуализация процесса конвертации

При загрузке `.astr` файла в прувер можно включить панель визуализации (кнопка "Show Conv"), которая показывает:

1. **Исходная строка** — текст в человекочитаемом виде
2. **Посимвольное разбиение** — каждый символ как отдельный запрос
3. **Цепочка связей** — формальное представление
4. **Результат верификации** — статус доказательства

### Пример визуализации

```
┌────────────────────────────────────────┐
│ Строка: "Hi"                            │
├────────────────────────────────────────┤
│ Символ 1: 'H' → (∞ -> 'H')             │
│ Символ 2: 'i' → ((∞ -> 'H') -> 'i')    │
├────────────────────────────────────────┤
│ Результат: ((∞ -> 'H') -> 'i')         │
└────────────────────────────────────────┘
```

## Связь с другими нотациями

### Формальная нотация → Строковое ачисло

Формула формальной нотации может быть представлена как строковое ачисло:

```
♂∞ → "♂∞" ≡ ((∞ -> '♂') -> '∞')
```

### Строковое ачисло → Четверичная нотация

Каждый символ UTF-8 кодируется как последовательность абитов:

```
'A' = 01000001₂ → [01000001]
```

## Специальные случаи

### Пустая строка

Пустая строка `""` интерпретируется как `∞`:

```
"" ≡ ∞
```

### Один символ

Один символ — связь с акорнем:

```
"c" ≡ (∞ -> 'c')
```

### Формальная нотация как строка

Символы формальной нотации сами являются UTF-8 символами и могут быть представлены как строковое ачисло:

```
"∞" ≡ (∞ -> '∞')
"→" ≡ (∞ -> '→')
```

## Реализация в коде

### Парсер строковых ачисел

```typescript
// src/core/stringAnum.ts

/**
 * Парсит содержимое .astr файла
 * @param content - содержимое файла
 * @returns массив AST узлов
 */
export function parseStringAnumFile(content: string): ASTNode[]

/**
 * Конвертирует строку в формальную нотацию
 * @param str - строка UTF-8
 * @returns строка формальной нотации
 */
export function stringAnumToFormal(str: string): string

/**
 * Конвертирует строку в AST
 * @param str - строка UTF-8
 * @returns узел AST
 */
export function stringToAST(str: string): ASTNode
```

### Пример использования

```typescript
import { stringAnumToFormal, parseStringAnumFile } from './core/stringAnum'

// Конвертация строки
const formal = stringAnumToFormal("связь")
// Результат: "(((((∞ -> 'с') -> 'в') -> 'я') -> 'з') -> 'ь')"

// Парсинг файла
const ast = parseStringAnumFile(`
// Пример
связь
link
`)
```

### Обработка в UI

```typescript
// При открытии файла .astr:
// 1. Читается содержимое файла
// 2. Каждая строка конвертируется в формальную нотацию
// 3. Отображается панель визуализации
// 4. Результат верифицируется прувером
```

## Онтологическая чистота

| Аспект | Статус | Описание |
|--------|--------|----------|
| Не «кодируют» данные | ✅ | Строковые ачисла **суть** конкретные связи |
| Нет разрыва знак↔связь | ✅ | Символ — запрос по форме, который резолвируется в связь |
| Замкнутость | ✅ | Преобразование происходит внутри асети |

## Практические примеры

### Загрузка файла

```
1. Открыть файл example.astr
2. Включить панель визуализации (Show Conv)
3. Просмотреть пошаговое преобразование
4. Проверить результат верификации
```

### Сохранение как строковое ачисло

```
1. Ввести данные в редактор
2. Выбрать "Сохранить как .astr"
3. Файл сохраняется как UTF-8 текст
```
