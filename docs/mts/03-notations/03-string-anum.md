# Строковые ачисла (.astr)

> **Статус:** Шаблон для будущего контента

## Краткое описание

Строковые ачисла — человекочитаемая форма сериализации связей.

## Формат

Строковое ачисло — это последовательность UTF-8 символов в двойных кавычках:

```
"связь" ≡ (∞ -> "связь")
```
