# EBNF грамматика

> **Статус:** Завершён
> **Источник:** `specification/v0.1.md`
> **Этап:** 5.4

## Назначение

EBNF (Extended Backus-Naur Form) — формальное описание синтаксиса всех трёх нотаций МТС. Используется для реализации парсеров и валидации входных данных.

| Характеристика | Значение |
|----------------|----------|
| Стандарт | ISO/IEC 14977 (EBNF) |
| Охват | Формальная, строковая, четверичная нотации |
| Применение | Лексер, парсер, валидация |

## Формальная нотация МТС

### Лексические соглашения

| Правило | Описание | Пример |
|---------|----------|--------|
| Пробелы и переводы строк | Разделители (игнорируются) | `a -> b` ≡ `a->b` |
| Комментарии | От `//` до конца строки | `// comment` |
| `!->` | Один токен (приоритет над `!` и `->`) | `a !-> b` |
| `!=` / `≠` / `¬=` | Один токен (неравенство) | `a != b` |
| `!` и `¬` | Синонимы инверсии | `!x` ≡ `¬x` |

### EBNF грамматика

```ebnf
(* Файл теории *)
File      ::= { Stmt } ;

(* Утверждение *)
Stmt      ::= Expr [ "," ] ;  (* запятая — необязательный разделитель *)

(* Выражение *)
Expr      ::= DefExpr
            | EqExpr
            | NeqExpr
            | Term ;

(* Определение *)
DefExpr   ::= Term ":" Term ;

(* Тождество *)
EqExpr    ::= Term "=" Term ;

(* Нетождество *)
NeqExpr   ::= Term NeqOp Term ;
NeqOp     ::= "!=" | "≠" | "¬=" ;

(* Терм *)
Term      ::= Chain ;

(* Цепочка связей (левоассоциативная) *)
Chain     ::= Pref { LinkOp Pref } ;
LinkOp    ::= "->" | "!->" ;

(* Префиксные операторы *)
Pref      ::= { NotOp | "♂" } Post ;
NotOp     ::= "!" | "¬" ;

(* Постфиксные операторы *)
Post      ::= Atom { "♀" | Pow } ;
Pow       ::= "^" Nat ;

(* Атом *)
Atom      ::= Const
            | Id
            | AbitLit
            | StringLit
            | Set
            | "(" Expr ")" ;

(* Пакет *)
Set       ::= "{" Expr { "," Expr } "}" ;

(* Константы *)
Const     ::= "∞" | "0" | "1" ;

(* Абитовый литерал *)
AbitLit   ::= "'" { AbitChar } "'" ;
AbitChar  ::= "[" | "0" | "1" | "]" ;

(* Строковый литерал *)
StringLit ::= '"' { Utf8Char } '"' ;

(* Идентификатор *)
Id        ::= Letter { Letter | Digit | "_" } ;

(* Натуральное число *)
Nat       ::= Digit { Digit } ;
```

### Диаграмма приоритетов

```
┌─────────────────────────────────────────────┐
│ Приоритет (от высшего к низшему)            │
├─────────────────────────────────────────────┤
│ 1. Атомы: ∞, 0, 1, Id, "...", '...', (...)  │
│ 2. Постфикс: ♀, ^n                           │
│ 3. Префикс: ♂, !, ¬                          │
│ 4. Связь: ->, !->                            │
│ 5. Определение: :                            │
│ 6. Тождество: =, !=                          │
└─────────────────────────────────────────────┘
```

### Примеры разбора

#### Пример 1: `♂∞ -> ∞♀`

```
Chain
├── Pref
│   ├── ♂
│   └── Post
│       └── Atom (∞)
├── ->
└── Pref
    └── Post
        ├── Atom (∞)
        └── ♀
```

#### Пример 2: `x : (♂x -> x)`

```
DefExpr
├── Term (x)
├── :
└── Term
    └── Chain
        ├── Pref
        │   ├── ♂
        │   └── Post
        │       └── Atom (x)
        ├── ->
        └── Pref
            └── Post
                └── Atom (x)
```

#### Пример 3: `{(x = y), (y = z)} -> (x = z)`

```
Chain
├── Pref
│   └── Post
│       └── Atom (Set)
│           ├── EqExpr (x = y)
│           └── EqExpr (y = z)
├── ->
└── Pref
    └── Post
        └── Atom
            └── EqExpr (x = z)
```

## Строковые ачисла (UTF-8)

### EBNF грамматика

```ebnf
(* Строковый файл *)
Utf8File   ::= { Utf8Line } ;

(* Строка (одно ачисло) *)
Utf8Line   ::= { Utf8Char } Newline ;

(* Любой UTF-8 символ *)
Utf8Char   ::= ? любой символ UTF-8 ? ;

(* Перевод строки *)
Newline    ::= "\n" | "\r\n" ;
```

### Интерпретация

Строка `c1c2...cn` интерпретируется как:
```
decode(c1c2...cn) := (((decode(c1) -> decode(c2)) -> ...) -> decode(cn))
```

где `decode(c)` — определение символа `c` через формальную нотацию.

## Четверичная (абитовая) нотация

### EBNF грамматика

```ebnf
(* Абитовый файл *)
AbitFile  ::= { AbitLine } ;

(* Строка (одно ачисло) *)
AbitLine  ::= AbitSeq Newline ;

(* Последовательность абитов *)
AbitSeq   ::= { AbitAtom } ;

(* Атом абитовой нотации *)
AbitAtom  ::= "0" | "1" | Ctx ;

(* Вложенный контекст *)
Ctx       ::= "[" AbitSeq "]" ;
```

### Допустимые символы

| Символ | Описание | Форма МТС |
|--------|----------|-----------|
| `0` | Нуль смысла | `∞♀ -> ♂∞` |
| `1` | Единица смысла | `♂∞ -> ∞♀` |
| `[` | Начало контекста | `♂∞` |
| `]` | Конец контекста | `∞♀` |

### Пример корректного ачисла

```
01010001[010100[1001]010]
```

Разбор:
- `01010001` — последовательность из 8 абитов
- `[...]` — вложенный контекст
  - `010100` — внутренняя последовательность
  - `[1001]` — глубоко вложенный контекст
  - `010` — окончание контекста

## Таблица токенов

### Формальная нотация

| Токен | Лексема | Описание |
|-------|---------|----------|
| `INFINITY` | `∞` | Акорень |
| `ZERO` | `0` | Нуль смысла |
| `ONE` | `1` | Единица смысла |
| `LINK` | `->` | Связь |
| `NEG_LINK` | `!->` | Инвертированная связь |
| `MALE` | `♂` | Самозамыкание начала |
| `FEMALE` | `♀` | Самозамыкание конца |
| `NOT` | `!` / `¬` | Инверсия |
| `DEF` | `:` | Определение |
| `EQ` | `=` | Тождество |
| `NEQ` | `!=` / `≠` / `¬=` | Нетождество |
| `LPAREN` | `(` | Открывающая скобка |
| `RPAREN` | `)` | Закрывающая скобка |
| `LBRACE` | `{` | Открывающая фигурная |
| `RBRACE` | `}` | Закрывающая фигурная |
| `POW` | `^` | Степень |
| `COMMA` | `,` | Запятая |
| `ID` | `[a-zA-Z_][a-zA-Z0-9_]*` | Идентификатор |
| `STRING` | `"..."` | Строковый литерал |
| `ABIT` | `'...'` | Абитовый литерал |

### Четверичная нотация

| Токен | Лексема | Описание |
|-------|---------|----------|
| `ABIT_ZERO` | `0` | Нуль |
| `ABIT_ONE` | `1` | Единица |
| `ABIT_OPEN` | `[` | Начало контекста |
| `ABIT_CLOSE` | `]` | Конец контекста |

## Реализация в коде

### Лексер

```typescript
// src/core/lexer.ts

export enum TokenType {
  INFINITY,    // ∞
  ZERO,        // 0
  ONE,         // 1
  LINK,        // ->
  NEG_LINK,    // !->
  MALE,        // ♂
  FEMALE,      // ♀
  NOT,         // ! или ¬
  DEF,         // :
  EQ,          // =
  NEQ,         // != или ≠
  LPAREN,      // (
  RPAREN,      // )
  LBRACE,      // {
  RBRACE,      // }
  POW,         // ^
  COMMA,       // ,
  ID,          // идентификатор
  STRING,      // "..."
  ABIT,        // '...'
  NUMBER,      // число
  EOF,         // конец файла
}

export interface Token {
  type: TokenType
  value: string
  line: number
  column: number
}

export function tokenize(input: string): Token[]
```

## Нормализация (десахаризация)

| Конструкция | Развёртка |
|-------------|-----------|
| `!` и `¬` | Синонимы — хранить как `!` |
| `a !-> b` | `!(a -> b)` |
| `a^1` | `a` |
| `a^(n+1)` | `(a^n -> a)` |

```typescript
// src/core/normalizer.ts

export function normalize(node: ASTNode): ASTNode

// Примеры:
// normalize(parse("a !-> b")) === normalize(parse("!(a -> b)"))

```
