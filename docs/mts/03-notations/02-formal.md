# Формальная нотация (.mtl)

> **Статус:** Шаблон для будущего контента
> **Источник:** `07-three-notations.md`
> **Этап:** 5.4

## Краткое описание

Формальная нотация — основной способ записи запросов по форме связей.

## Алфавит

| Символ | Описание |
|--------|----------|
| `∞` | Акорень |
| `->` | Связь |
| `!->` | Инвертированная связь |
| `♂` | Начало (Male) |
| `♀` | Конец (Female) |
| `!` | Инверсия |
| `:` | Определение |
| `=` | Равенство |
| `!=` | Неравенство |
| `{}` | Множество |
| `()` | Группировка |
