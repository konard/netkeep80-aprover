# Формальная нотация (.mtl)

> **Статус:** Завершён
> **Источники:** `07-three-notations.md`, `specification/v0.1.md`
> **Этап:** 5.4

## Назначение

Формальная нотация — основной способ записи запросов по форме связей. Используется для записи аксиом, лемм, теорем и математических объектов как запросов к формам связей в асети.

| Характеристика | Значение |
|----------------|----------|
| Расширение файлов | `.mtl` (Metatheory Language) |
| Онтологический статус | Язык запросов по форме |
| Область применения | Теоретическое описание, доказательства |

## Алфавит формальной нотации

### Константы

| Символ | Описание | Аксиома | Форма |
|--------|----------|---------|-------|
| `∞` | Акорень | А4 | `∞ : (∞ -> ∞)` |
| `1` | Единица смысла | А8 | `1 : (♂∞ -> ∞♀)` |
| `0` | Нуль смысла | А9 | `0 : !1` |

### Конструкторы

| Символ | Описание | Позиция | Аксиома | Пример |
|--------|----------|---------|---------|--------|
| `->` | Связь (начало, конец) | инфикс | А3 | `a -> b` |
| `!->` | Инвертированная связь | инфикс | А7 | `a !-> b` ≡ `!(a -> b)` |
| `♂` | Самозамыкание начала | префикс | А5 | `♂x` |
| `♀` | Самозамыкание конца | постфикс | А6 | `x♀` |

### Метаоператоры

| Символ | Описание | Аксиома | Пример |
|--------|----------|---------|--------|
| `:` | Определение (акт различения формы) | А0 | `s : F` |
| `=` | Структурная тождественность | А1 | `x = y` |
| `!=` / `≠` / `¬=` | Нетождественность | — | `x != y` |

### Унарные операторы

| Символ | Описание | Аксиома | Свойства |
|--------|----------|---------|----------|
| `!` / `¬` | Инверсия направленности | А7 | `!!x = x`, `!(a -> b) = (b -> a)` |

### Группировка и контейнеры

| Символ | Описание | Назначение |
|--------|----------|------------|
| `( )` | Круглые скобки | Переопределение порядка композиции запросов |
| `{ }` | Фигурные скобки | Пакет (контейнер) множества выражений |

## Онтологический статус символов

Каждый символ формальной нотации — уже связь, определённая своим паттерном формы:

```
∞   : запрос ко всем связям формы (x = x -> x)
♂x  : запрос ко всем связям формы (y = y -> x)
x♀  : запрос ко всем связям формы (y = x -> y)
a->b: запрос к связям с началом формы a и концом формы b
```

## Приоритеты операторов

| Приоритет | Оператор | Ассоциативность | Описание |
|-----------|----------|-----------------|----------|
| 1 (высший) | `♂` | правая | Самозамыкание начала |
| 2 | `♀` | левая | Самозамыкание конца |
| 3 | `!` / `¬` | правая | Инверсия |
| 4 | `->` / `!->` | левая | Связь |
| 5 | `:` | — | Определение |
| 6 (низший) | `=` / `!=` | — | Тождественность |

## Синтаксические соглашения

| Правило | Описание | Пример |
|---------|----------|--------|
| Левоассоциативность `->` | `a -> b -> c` ≡ `(a -> b) -> c` | `∞ -> ∞ -> ∞` ≡ `((∞ -> ∞) -> ∞)` |
| Правоассоциативность `♂` | `♂♂x` ≡ `♂(♂x)` | `♂♂∞` ≡ `♂(♂∞)` |
| Левоассоциативность `♀` | `x♀♀` ≡ `(x♀)♀` | `∞♀♀` ≡ `(∞♀)♀` |
| Скобки группировки | Явное переопределение порядка | `a -> (b -> c)` ≠ `a -> b -> c` |
| Пакет `{}` | Неупорядоченное множество | `{A, B}` ≡ `{B, A}` |

## Примеры выражений

### Базовые выражения

```mtl
// Акорень — полное самозамыкание
∞ : (∞ -> ∞)

// Самозамыкание начала
♂x : (♂x -> x)

// Самозамыкание конца
x♀ : (x -> x♀)

// Единица смысла
1 : (♂∞ -> ∞♀)

// Нуль смысла
0 : !1
```

### Определения и тождества

```mtl
// Определение знака
s : (∞ -> ∞)

// Тождественность
x = x

// Симметрия равенства
(x = y) -> (y = x)

// Транзитивность
{(x = y), (y = z)} -> (x = z)
```

### Конгруэнция

```mtl
// Конгруэнция по связи
{(a = c), (b = d)} -> ((a -> b) = (c -> d))

// Конгруэнция по началу
(a = b) -> (♂a = ♂b)

// Конгруэнция по концу
(a = b) -> (a♀ = b♀)
```

### Инверсия

```mtl
// Инволюция
!!x = x

// Инверсия связи
!(a -> b) = (b -> a)

// Дуальность самозамыканий
!(♂x) = x♀
!(x♀) = ♂x

// Самодуальность акорня
!∞ = ∞
```

## Формат файла .mtl

```mtl
// Комментарии начинаются с //

// Определения
∞ : (∞ -> ∞)
1 : (♂∞ -> ∞♀)
0 : !1

// Тождества
(1 = !0)
(0 = !1)

// Теоремы с пакетами
{(x = y), (y = z)} -> (x = z)

// Левоассоциативность
(a -> b -> c) = ((a -> b) -> c)
```

## Лексические соглашения

| Правило | Описание |
|---------|----------|
| Пробелы и переводы строк | Разделители (игнорируются) |
| Комментарии | От `//` до конца строки |
| `!->` | Один токен (приоритет над `!` и `->`) |
| `!=` / `≠` / `¬=` | Один токен (неравенство) |
| `!` и `¬` | Синонимы инверсии |

## Реализация в коде

### Лексический анализатор

```typescript
// src/core/lexer.ts
export enum TokenType {
  INFINITY,      // ∞
  LINK,          // ->
  NEG_LINK,      // !->
  MALE,          // ♂
  FEMALE,        // ♀
  NOT,           // ! или ¬
  DEF,           // :
  EQ,            // =
  NEQ,           // != или ≠ или ¬=
  LBRACE,        // {
  RBRACE,        // }
  LPAREN,        // (
  RPAREN,        // )
  ZERO,          // 0
  ONE,           // 1
  ID,            // идентификатор
  // ...
}

export function tokenize(input: string): Token[]
```

### Синтаксический анализатор

```typescript
// src/core/parser.ts
export function parse(input: string): ASTNode[]
export function parseExpr(input: string): ASTNode

// Рекурсивный спуск по грамматике EBNF
function parseFile(): ASTNode[]
function parseStmt(): ASTNode

```

### AST типы

```typescript
// src/core/ast.ts
export type ASTNode =
  | Infinity        // ∞
  | Link            // a -> b
  | Male            // ♂x
  | Female          // x♀
  | Not             // !x
  | Def             // s : F
  | Eq              // A = B
  | Neq             // A != B
  | Set             // { ... }
  | Zero            // 0
  | One             // 1
  | Id              // идентификатор
  | StringLit       // "..."
  | AbitLit         // '...'
```
