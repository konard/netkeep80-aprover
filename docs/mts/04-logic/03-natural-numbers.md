# Натуральные числа в МТС

> **Статус:** Рефакторинг завершён
> **Источник:** `11-natural-numbers.md`
> **Этап:** 5.5

## Краткое описание

В МТС натуральное число — это **структурная характеристика последовательности связей**: её длина как мера повторения акта связывания. Число `n` — это не символ, обозначающий количество, а сама форма последовательности длины `n`.

---

## 1. Онтологический фундамент числа

| Классический подход | МТС |
|---------------------|-----|
| Число = количество объектов | Число = длина последовательности связей |
| Число существует «само по себе» | Число возникает как свойство формы связи |
| Арифметика — внешняя структура | Арифметика — внутреннее свойство асети связей |

Число в МТС не является «объектом» или «количеством». Это принципиально отличает МТС от всех классических подходов.

---

## 2. Формализация длины через оператор степени

Для любой связи `a` и натурального числа `n ≥ 1` оператор степени определяет **длину последовательности**:

```
a¹ = a
a² = (a -> a)
a³ = ((a -> a) -> a)
...
aⁿ = (...((a -> a) -> a) ... -> a)  // n раз, левоассоциативно
```

**Ключевой инсайт**: длина `n` — это не мета-свойство, а **форма самой связи** `aⁿ`. Связь `aⁿ` и есть число `n` в его онтологическом проявлении.

---

## 3. Аксиомы Пеано-МТС

### А1. Аксиома единицы смысла как базовой длины

```
1 : (♂∞ -> ∞♀)
```

**Содержание**: Символ `1` определяет запрос ко всем связям формы направленной связи между началом и концом смысла. Это минимальная ненулевая длина — один акт связывания. Единица не «существует», она **есть** акт различения начала и конца.

### А2. Аксиома инкремента как удлинения последовательности

```
∀a ∀n (aⁿ⁺¹ = (aⁿ -> a))
```

**Содержание**: Следующая длина возникает как присоединение новой связи `a` к уже существующей последовательности длины `n`. Это не «прибавление», а **онтологическое наращивание структуры** через акт связывания.

### А3. Аксиома уникальности длин

```
∀a ∀m ∀n ((aᵐ = aⁿ) -> (m = n))
```

**Содержание**: Если две последовательности из одной и той же связи `a` структурно тождественны, то их длины совпадают. Уникальность следует из аксиомы тождественности связей.

### А4. Аксиома запрета самозамыкания для конечных длин

```
∀a ∀n ((n ≥ 1) -> (aⁿ != ∞))
```

**Содержание**: Никакая конечная последовательность связей не может быть полностью самозамкнутой. Это гарантирует, что числа остаются **открытыми структурами**, способными к дальнейшему удлинению. Только ∞ обладает свойством `x = (x -> x)`.

### А5. Аксиома индукции как структурной наследственности

```
∀P (
  (P(1) = true) ->
  (∀n ((P(n) = true) -> (P(n+1) = true))) ->
  (∀n (P(n) = true))
)
```

**Содержание**: Если свойство `P` истинно для базовой длины `1` и сохраняется при удлинении последовательности, то оно истинно для всех длин. Индукция здесь — не мета-принцип, а **структурное свойство асети связей**.

---

## 4. Избежание парадоксов стандартной арифметики

### Парадокс «бесконечного числа»

**Проблема**: В Пеано-арифметике возникает вопрос: «Существует ли бесконечное натуральное число?» — что ведёт к противоречиям в нестандартных моделях.

**Решение МТС**: Бесконечная длина формализуется не как «число», а как особая форма связи:

```
a^∞ = ♂a
```

Здесь `♂a` — не «бесконечное число», а **самозамкнутое начало**, качественно отличное от всех конечных длин `aⁿ`. Разрыв между конечным и бесконечным онтологически фиксирован аксиомой А4.

### Парадокс самоприменения

**Проблема**: В теоретико-множественных основаниях арифметики возникает парадокс при попытке собрать «все натуральные числа» в одно множество.

**Решение МТС**: Натуральные числа не «собираются» — они **уже существуют как формы в асети связей**. Нет «множества всех чисел», есть асеть, содержащая все связи форм `a¹, a², a³, ...`. Поскольку асеть — это не множество, а сеть связей, парадокс самоприменения невозможен.

### Проблема основания индукции

**Проблема**: В классической арифметике индукция принимается как недоказуемый принцип.

**Решение МТС**: Индукция выводится из структурных свойств асети:

- Акорень `∞` обеспечивает существование базового случая (`1`)
- Оператор `->` обеспечивает возможность удлинения (`n+1`)
- Аксиома тождественности обеспечивает уникальность каждой длины
- Аксиома запрета самозамыкания гарантирует открытость структуры

Индукция здесь — не постулат, а **следствие онтологической структуры связей**.

## 5. Кодирование чисел в ачислах

Любое натуральное число `n` однозначно кодируется как ачисло — последовательность абитов, начинающаяся с ∞:

```
1 = ∞1
2 = ∞11
3 = ∞111
...
n = ∞(1ⁿ)  // n повторений абита '1'
```

Где абит `1` определён как:

```
'1' : 1 = (♂∞ -> ∞♀)
```

### Пример полного разворачивания числа 3

```
∞111 = ∞ -> 1 -> 1 -> 1
     = ∞ -> (♂∞ -> ∞♀) -> (♂∞ -> ∞♀) -> (♂∞ -> ∞♀)
```

Это не «представление» числа — это **само число как связь** в асети.

---

## 6. Арифметические операции

### Сложение

```
aᵐ + aⁿ = aᵐ⁺ⁿ
```

Сложение — это конкатенация последовательностей связей.

### Умножение

```
aᵐ × aⁿ = (aᵐ)ⁿ
```

Умножение — это повторение последовательности.

### Порядок

```
m < n ⟺ ∃k (m + k = n ∧ k ≥ 1)
```

Порядок определяется через существование дополнительной длины.

---

## Реализация в коде

```typescript
// src/core/normalizer.ts — Десахаризация оператора степени
function desugarPower(node: PowerExpr): ASTNode {
  const { base, exponent } = node;

  if (exponent === 1) {
    return base;
  }

  // aⁿ = (...((a -> a) -> a) ... -> a) — левоассоциативно
  let result = base;
  for (let i = 1; i < exponent; i++) {
    result = { type: 'Link', left: result, right: base };
  }

  return result;
}
```

## Итог

В МТС натуральные числа избегают парадоксов классической арифметики потому, что:

1. **Нет разделения «форма ↔ содержание»**: число `n` — это не символ, обозначающий количество, а сама форма последовательности длины `n`

2. **Нет внешнего универсума**: числа не «существуют в модели» — они суть структурные паттерны асети связей

3. **Рекурсия дисциплинирована**: аксиома А4 (`aⁿ != ∞`) и ограждённая рекурсия гарантируют, что конечные длины никогда не коллапсируют в самозамыкание

4. **Индукция конструктивна**: она следует из структуры асети, а не принимается как недоказуемый принцип

> Число в МТС — это не абстракция, а **конкретная связь с определённой структурной формой**. Арифметика становится не «языком о количествах», а **онтологией последовательностей связей**.
