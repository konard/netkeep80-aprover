# Онтология различения

> **Статус:** Готово ✅
> **Этап:** 5.2

## Минимальный онтологический акт

Первое различение не возникает «между чем-то» — оно само является первичным онтологическим актом. Различение не предполагает предсуществующих состояний; напротив, акт различения одновременно:

1. **Совершает разделение** — создаёт возможность «было/стало»
2. **Фиксирует целостность** — немедленно удерживает это различение как устойчивую форму

Эти два аспекта неразделимы. Различение без фиксации исчезает в момент возникновения. Фиксация без различения невозможна — нет чего фиксировать.

---

## Связь как единица различения

Минимальный онтологический акт — это **неделимая тройственность**:

```
d ≡ b -> e
```

| Символ | Значение |
|--------|----------|
| `d` | Различие как целостность (не «между», а само различение) |
| `b` | Смысл начала (фиксированная форма предшествующего различения) |
| `e` | Смысл конца (новая форма) |
| `->` | Акт связывания — онтологический конструктор существования |

### Неделимость связи

Критически важно: связь **не конструируется** из начала и конца. Начало, конец и связь возникают синхронно в одном акте. Нет «сначала начало и конец, потом связь» — есть только акт, в котором все три аспекта возникают одновременно как неделимая целостность.

Это выражено аксиомой А3 (Связь):

```
be : (b -> e)
```

Знак `be` обозначает связь, форма которой `(b -> e)`. Связь и её форма возникают синхронно.

## Возникновение акорня

Первый акт различения требует условия своей возможности — формы, которая делает различение устойчивым. Этой формой является **акорень**:

```
∞ : (∞ -> ∞)
```

Это не циклическое определение, а **синхронное возникновение**:

| Элемент | Значение |
|---------|----------|
| `∞` слева от `:` | Потенциальная возможность различения |
| `∞ -> ∞` справа | Конкретная форма этой возможности |
| `:` | Акт самоопределения, создающий устойчивость |

∞ не существует «до» различения. Он возникает синхронно с первым актом как его **форма самотождественности** — условие, при котором различение может быть зафиксировано.

---

## Последовательность различений

После возникновения акорня становятся возможны конкретные различения:

```
// Первое конкретное различение:
d₁ : (∞ -> e₁)

// Второе различение:
d₂ : (d₁ -> e₂)

// Третье различение:
d₃ : (d₂ -> e₃)
...
```

Каждый последующий акт использует предыдущее различение как начало для нового различения. Так формируется **цепочка связей**.

---

## Онтологический вывод

Связь — это и есть зафиксированное различие. Различение и его фиксация неотделимы:

- Без фиксации различение исчезает
- Без различения нет чего фиксировать

Поэтому в МТС нет первичных «объектов», из которых строятся связи. **Связь — первичная онтологическая категория**.

То, что традиционно называют «объектом», в МТС является устойчивым паттерном связей — формой, которая сохраняет свою структуру при последовательных актах различения.

> *Существовать — значит быть связью.*

---

## Самозамыкание

Специальные формы связей, где начало или конец совпадают с самой связью:

| Форма | Определение | Смысл |
|-------|-------------|-------|
| `♂x` | `♂x : (♂x -> x)` | Начало замкнуто на связь |
| `x♀` | `x♀ : (x -> x♀)` | Конец замкнут на связь |
| `∞` | `∞ : (∞ -> ∞)` | Полное самозамыкание |

Самозамыкание обеспечивает устойчивость различения — связь, замкнутая на себя, не зависит от внешних условий.
