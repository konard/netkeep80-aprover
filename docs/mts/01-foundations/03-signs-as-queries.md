# Знаки как запросы по форме

> **Статус:** Готово ✅
> **Этап:** 5.2

## Семиотика МТС

Классическая семиотика утверждает: **знак → объект** (референция). Это создаёт непреодолимый разрыв: знак существует в сознании, объект — в мире.

МТС радикально переосмысливает природу знака:

> **Знак не ссылается на связь — знак есть оператор различения формы в асети связей.**

---

## Первичный акт: различение без объектов

Субъект фиксирует только последовательность различий:

```
состояние A → состояние B → различие d₁
d₁ → состояние C → различие d₂
d₂ → состояние D → различие d₃
...
```

Больше субъект ничего не различает. Нет «объектов», нет «свойств», нет «внешнего мира» — есть только акты различения.

МТС делает предположение: по ту сторону субъекта существует **асеть связей**, и каждое различение `dₖ` соответствует некоторой связи в этой асети. Но субъект никогда не имеет прямого доступа к связям — он работает только со своими различиями.

---

## Знак как запрос по форме

Запись `∞ : (∞ -> ∞)` читается не как «символ ∞ обозначает связь ∞», а как:

> «Пусть знак `∞` задаёт паттерн поиска: найти все связи, удовлетворяющие форме `x = x -> x`».

Это не ссылка, а **запрос по форме** — критерий отбора из «океана связей».

### Примеры запросов

| Знак | Запрос по форме | Результат резолюции |
|------|-----------------|---------------------|
| `∞` | `x = x -> x` | Связи с полным самозамыканием |
| `♂x` | `y = y -> x` | Связи с самозамкнутым началом |
| `x♀` | `y = x -> y` | Связи с самозамкнутым концом |

---

## Аксиома определения (А0)

Аксиома определения устанавливает связь между актом различения формы и фактом структурной тождественности:

```
(s : F) -> (s = F)
```

| Символ | Значение |
|--------|----------|
| `s` | Знак как паттерн различения |
| `F` | Форма связи (конструкция из операторов `->, ♂, ♀`) |
| `:` | Конструктор акта различения формы |
| `=` | Констатация структурной тождественности |
| `->` | Онтологический акт порождения |

### Различие `:` и `=`

| Оператор | Природа | Направленность |
|----------|---------|----------------|
| `:` | Процесс установления соответствия | Ориентирован: `(s : F) ≠ (F : s)` |
| `=` | Факт неразличимости по форме | Симметрична: `s = F ⇔ F = s` |

---

## Процесс резолюции

Как работает резолюция запроса:

```
Шаг 1: Знак "∞" вводится как запрос по форме (акт :)
       ∞ : (∞ -> ∞)

Шаг 2: Запрос разрешается в асети связей (акт ->)
       ∃!x (x = x -> x) → x есть результат резолюции

Шаг 3: Факт тождественности (акт =)
       ∞ = результат_резолюции
```

### Почему это не цикличность?

Классическое возражение: «`∞ : (∞ -> ∞)` — циклическое определение».

Это возражение основано на ошибочном предположении: знак должен сначала существовать как имя, а затем ссылаться на уже существующий объект.

В МТС действует иной принцип:

> **Паттерн формы и его резолюция возникают синхронно в едином акте онтологического различения.**

Нет цикла «имя → объект → имя», потому что:
- Знак `∞` не «ссылается» на связь — он задаёт критерий отбора
- Связь не «определяется» знаком — она удовлетворяет форме запроса
- Резолюция происходит в асети, где связи существуют независимо от знаков

---

## Устранение разрыва «знак ↔ связь»

Разрыв в классической семиотике возникает из двойственности:
- Знак — в субъективном поле (сознание)
- Объект — в объективном поле (мир)

МТС устраняет этот разрыв:

> **Знак и связь существуют в одном онтологическом поле — поле различений.**

```
Субъект фиксирует различие d₁ → вводит знак s₁ как паттерн формы
Субъект фиксирует различие d₂ → вводит знак s₂ как паттерн формы
...
Знак s₁ сам является различением → следовательно, знак есть связь
```

Каждый знак — это уже связь, определённая своим паттерном формы. Формальная нотация МТС не описывает связи извне — она сама есть последовательность связей.

---

## Онтологическая чистота

Подход «знак как запрос по форме» обеспечивает:

✅ Нет внешних объектов — всё есть связи
✅ Нет скрытых параметров — знак явно задаёт форму различения
✅ Нет разрыва «знак ↔ связь» — оба суть различения в едином поле
✅ Нет цикличности — есть синхронное возникновение паттерна и резолюции
✅ Самодостаточность — язык описания есть часть описываемой онтологии

---

## Пример: аксиома смысла

Разберём `∞ : (∞ -> ∞)` по шагам:

| Шаг | Акт | Описание |
|-----|-----|----------|
| 1 | `:` | Введём знак `∞` как паттерн поиска всех связей формы `x = x -> x` |
| 2 | `->` | Из акта различения возникает связь между знаком и формой |
| 3 | `=` | Знак `∞` структурно тождественен связи, удовлетворяющей форме |

- Символ `∞` слева от `:` — не «имя», а **потенциальная возможность различения**
- Форма `∞ -> ∞` справа — **конкретная структура этого различения**
- Связка `:` — **онтологический акт самоопределения**

Это не циклическое определение, а **генеративный акт**: возможность различения получает устойчивую форму через самозамыкание.
